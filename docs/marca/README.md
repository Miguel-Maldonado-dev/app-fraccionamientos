# Identidad de WEADMI

Material de marca de la aplicación. Es la fuente de verdad para aplicar la identidad a toda la interfaz.

## Qué poner aquí

- `identidad.md`: nombre, tono, paleta de colores (con valores HEX), tipografías, uso del logo y cualquier regla de estilo.
- `logos/`: los archivos del logo (de preferencia SVG; también PNG si los tienes), en sus variantes: completo, solo símbolo, versión clara y oscura.
- `fuentes/`: archivos de fuentes, si la tipografía no está en Google Fonts.

Los archivos que la app sirva directamente (logos, favicon) se copiarán después a `public/` o `src/app/` al aplicar la identidad. Aquí se queda el original.
